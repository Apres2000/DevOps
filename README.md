# Ansible Docker Automation Project

Проект автоматизации развертывания веб-сервера Nginx в Docker-контейнере на удаленных серверах с помощью Ansible.

## Структура проекта
* `deploy_docker.yml` — Ansible-плейбук для автоматизации деплоя контейнера.
* `.gitignore` — файлы, исключенные из репозитория (секреты, инвентарь).

## Как запустить
1. Настройте файл инвентаря `hosts.ini`.
2. Убедитесь в наличии SSH-доступа по ключам.
3. Запустите команду:
   ```bash
   ansible-playbook -i hosts.ini deploy_docker.yml
   ```
