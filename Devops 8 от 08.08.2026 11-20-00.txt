Начнем с самого фундамента мониторинга — Prometheus и Node Exporter.
Это «глаза» твоей системы. Prometheus будет собирать и хранить данные, а Node Exporter — это агент, который «снимает» показания с твоего сервера Timeweb (нагрузку на процессор, занятую оперативку, место на диске) и отдает их Прометею.
Раз мы решили двигаться по пути DevOps, делать всё будем «по-взрослому» — через наш docker-compose.yml, чтобы автоматизация (GitHub Actions) сама подхватила новые сервисы.
Шаг 9.1: Модернизация docker-compose.yml
Зайди на сервер в папку проекта cd ~/my_project и открой конфиг nano docker-compose.yml. Нам нужно добавить туда два новых сервиса.
Добавь эти блоки в раздел services::
yaml
  prometheus:
    image: prom/prometheus:latest
    container_name: prometheus
    volumes:
      - ./prometheus.yml:/etc/prometheus/prometheus.yml
    ports:
      - "9090:9090"
    restart: always

  node-exporter:
    image: prom/node-exporter:latest
    container_name: node-exporter
    restart: always
    ports:
      - "9100:9100"
Используйте код с осторожностью.
Шаг 9.2: Создание конфига для Prometheus
Prometheus не знает сам по себе, откуда брать данные. Нужно создать для него «карту».
В той же папке ~/my_project создай файл nano prometheus.yml и вставь туда:
yaml
global:
  scrape_interval: 15s # Как часто собирать данные

scrape_configs:
  - job_name: 'node'
    static_configs:
      - targets: ['node-exporter:']
Используйте код с осторожностью.
