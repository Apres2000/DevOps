Что нужно изменить в скрипте
Тебе понадобится добавить в переменные скрипта Токен твоего бота и твой Chat ID (из наших прошлых бесед я помню твой ID — 722603719).
Вот пример того, как должен выглядеть блок отправки в твоем скрипте:
bash
#!/bin/bash

# Настройки
THRESHOLD=80  # Порог срабатывания в процентах
TOKEN="ТВОЙ_ТОКЕН_БОТА"
CHAT_ID="722603719"

# Проверка использования диска (для корневого раздела /)
USAGE=$(df -h / | awk 'NR==2 {print $5}' | sed 's/%//')

# Если место превышает порог

Да, всё верно! Мы настраивали SSH-псевдоним (alias), чтобы вместо длинной строки с IP-адресом и логином ты мог просто писать короткую фразу, например ssh wds. 
Если сейчас эта команда не работает или запрашивает пароль, вот что могло измениться:
1. Файл конфигурации на твоем компьютере
Все короткие имена хранятся в специальном текстовом файле config на твоей рабочей машине (не на сервере).
Где он находится: В Windows путь обычно выглядит так: C:\Users\Твое_Имя\.ssh\config.
Что могло случиться: Файл мог быть случайно удален, переименован или в нем изменились данные (например, IP сервера после переустановки на Timeweb). 
Как проверить и исправить:
Открой этот файл (можно через notepad %USERPROFILE%\.ssh\config в PowerShell) и убедись, что там есть такой блок: 

linsnotes.com
text
Host wds
    HostName IP_ТВОЕГО_СЕРВЕРА
    User root
    IdentityFile ~/.ssh/id_rsa
Используйте код с осторожностью.
2. Права доступа к ключам
SSH очень строг к безопасности. Если права на файлы ключей или папку .ssh стали слишком «открытыми» (например, их может читать кто-то еще на компьютере), система может игнорировать ключи и снова требовать пароль.

powershell
# Создаем папку .ssh, если её вдруг нет
if (!(Test-Path $HOME\.ssh)) { New-Item -Path $HOME\.ssh -ItemType Directory }

# Записываем настройки для wds
@"
Host wds
    HostName IP_ТВОЕГО_СЕРВЕРА
    User root
    IdentityFile ~/.ssh/id_rsa
"@ | Out-File $HOME\.ssh\config -Encoding utf8
Используйте код с осторожностью.
После этого команда ssh wds снова должна заработать.
